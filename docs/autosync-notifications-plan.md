# Оповещения автосинхронизации — только суперпользователю и назначенным — план

Статус: **сделано** (2026-11-25, v2.47.000). Решения
пользователя — раздел «Решения»; предложение ниже приведено к ним. Связано: `docs/watch-folder-autosync-design.md`
(раздел «Telegram», этапы 4–5), `docs/telegram-library-bot.md`.

## Желание пользователя

Результаты автосинхронизации должны получать **только суперпользователь
и/или назначенный пользователь** — в Telegram, через бота, — а не все
подряд.

## Как сейчас

`notify()` в `fb2parser_core/autosync_service.py` после планового скана шлёт
через Bot API по двум адресам, оба заданы вручную в `config.json`, раздел
`autosync` (вкладка «Расписание»):

- **`telegram_channel`** — сводка новинок (что легло в библиотеку). Канал
  общий для всех, кто привязал Telegram к библиотеке; в него попадают
  только книги, открытые всем (`include`, docs/multiuser-design.md).
- **`telegram_admin_chat`** — один чат по числовому id: итог запуска,
  спорные порции со ссылкой на «Входящие», сообщения с кнопками жанра
  (`_send_batch_prompts`). Нажатия кнопок `telegram_bot.AdminBot`
  принимает только из этого чата.

Сейчас (2026-11-25) канал и chat id заданы только на сервере 2; на основном
сервере для автосинхронизации есть только токен.

## Предложение

1. **Получатели — учётные записи сайта, а не chat id.** В настройках
   (вкладка «Расписание», только суперпользователь) — список «Кому присылать
   оповещения автосинхронизации»: только пользователи, привязавшие Telegram
   к библиотечному боту (`TelegramLink`). По умолчанию отмечены все
   суперпользователи; остальных отмечает суперпользователь. Сообщения — тем
   же ботом в личный чат каждому отмеченному. Ручной chat id и кнопка
   «Найти chat id» становятся не нужны.
   *Сделано так:* `notify_users` в разделе `autosync` config.json — id
   отмеченных учётных записей (`None` — все суперпользователи);
   `telegram_users.autosync_recipients`, кнопки — `can_decide_autosync`.
   «Chat id суперпользователя» оставлен: он нужен кодам входа и по-прежнему
   получает оповещения.

2. **Что получает каждый получатель** (решение пользователя: назначенный
   получает ту же информацию, что и суперпользователь; видимость книг — по
   прежним правилам):

   | | Суперпользователь | Назначенный пользователь |
   |---|---|---|
   | Итог запуска (разложено, ждут решения, сбои) | да | да |
   | Список новых книг | все | видимые ему (`visibility`) — книги автосинхронизации кладёт суперпользователь и они открыты всем, так что на деле тот же список |
   | Спорные порции (что ждёт решения и почему) | да | да |
   | Кнопки выбора жанра | да | нет — только сообщения |
   | Ссылка на «Входящие» | да | нет — страница только для суперпользователя |

   Нажатие кнопки проверяется по привязанной учётной записи
   (`linked_user(tg_id).is_superuser`), а не по одному chat id.

3. **Канал новинок — без изменений.** Автосинхронизация подразумевает,
   что книги вносит суперпользователь и они открыты всем, поэтому сводка
   новинок по-прежнему уходит в канал (решение пользователя). Выключатель не
   нужен.

4. **Мелочи:**
   - получатель заблокировал бота — остальным сообщения уходят, ошибка —
     в лог (`explain_error`), запуск не срывается;
   - смена списка получателей — в журнал действий («было → стало», как
     другие настройки; имена пользователей — только суперпользователю);
   - разовый перенос: текущий `telegram_admin_chat` сервера 2 становится
     отмеченным пользователем, если этот chat id принадлежит привязанной
     учётной записи; иначе — остаётся как есть до ручной настройки;
   - «уже сказано» (`admin_pending`, `tg_prompted`) — по получателю, чтобы
     новый получатель не терял сообщения, а старые не получали повторов.

5. **Тесты:** рассылка только отмеченным; назначенный пользователь не видит
   чужих книг и не получает кнопок; кнопка от не-суперпользователя ничего
   не делает; назначенный получает итог и спорные порции без кнопок и без
   ссылки на «Входящие»; заблокированный бот у одного получателя не мешает
   остальным.

## Решения (2026-11-25)

- Назначенный пользователь получает ту же информацию, что и
  суперпользователь: итог запуска, новые книги, спорные порции.
- Видимость книг — по прежним правилам (`visibility`), исключений нет.
- Назначенному — только сообщения, без кнопок выбора жанра.
- Ссылку на «Входящие» назначенному не показывать.
- Канал новинок остаётся как есть: книги автосинхронизации вносит
  суперпользователь, они открыты всем.

## Отложено

- Размещение пользователями своих книг и их видимость остальным —
  обсуждается отдельно, позже.
