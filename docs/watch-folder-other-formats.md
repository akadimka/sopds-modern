# Не-FB2 файлы в папке наблюдения и в исходниках — план

Статус: **обсуждается** (2026-11-24). Решения пользователя по вопросам из
раздела «Открытые вопросы» ещё не приняты. Реализация не начата.
Связано: `docs/watch-folder-autosync-design.md`.

## Проблема

Синхронизация (ручная и автосинхронизация — код общий,
`SynchronizationService`) работает только с `.fb2`/`.fb2.zip`. После того
как книги порции ушли в библиотеку, уборка
(`_cleanup_empty_folders` → `_remove_dir_if_no_fb2`) удаляет **целиком**
каждую подпапку обработанной порции, в которой сейчас нет FB2, — вместе
с EPUB, PDF, DJVU и любыми другими файлами. Проверено 2026-11-24 на
временной папке:

| Было в папке наблюдения | После уборки |
|---|---|
| Порция А: спорная `.fb2` (осталась), `EPUB/книга.epub`, `Обложки/cover.jpg`, `Серия 1/читать.txt` (FB2 отсюда ушли) | осталась только спорная `.fb2`; `EPUB`, `Обложки`, `Серия 1` удалены |
| Порция Б: разобрана целиком, остались `книга.epub`, `Серия/описание.txt` | удалена вся |
| Порция В: только `.epub`, FB2 не было | не тронута (синхронизация её не выбирает) |

То есть:

- порции **без единого FB2** не трогаются — но тогда их файлы копятся в
  папке наблюдения бесконечно;
- в порции, из которой хоть что-то ушло в библиотеку, не-FB2 файлы
  **молча пропадают**.

Пользователь не хочет, чтобы такие файлы копились, и хочет, чтобы они
тоже раскладывались по папкам авторов.

## Что уже есть

- Каталог SOPDS индексирует `.pdf .djvu .fb2 .epub .mobi`
  (`sopds_config.book_extensions`), т. е. разложенные в библиотеку файлы
  этих форматов сразу видны на сайте и в OPDS.
- `book_tools/format/` — разбор метаданных EPUB (`epub.py`: OPF —
  автор, название, серия Calibre, темы) и MOBI (`mobi.py`, EXTH — автор,
  название). Сейчас используется только каталогом, fb2parser — нет.
- Нормализация имени автора (`AuthorNormalizer`, замены
  `author_surname_conversions`), память библиотеки (где лежат автор и
  серия, `library_memory.db`), «Входящие» и Telegram-кнопки — всё это
  можно применить и к не-FB2 файлам.
- Сейчас (2026-11-24): в библиотеке основного сервера — только FB2; в
  `\\turnkey\Docs\Books` — 312 FB2 и 1 DJVU. Объём таких файлов пока мал.

## Как определять автора, серию и жанр

По убыванию надёжности:

1. **По соседям-FB2** (любой формат). Файл лежал в той же папке раздачи,
   что и FB2, которые ушли в библиотеку, — автор и серия у него те же;
   кладётся рядом с ними (та же папка автора/серии). Если имя файла
   совпадает с названием одного из этих FB2 — это та же книга в другом
   формате (см. «дубли форматов»). Жанр — тот же, что у соседей.
2. **EPUB / MOBI / AZW3 — по метаданным внутри**: автор, название,
   серия и номер (`calibre:series`, `calibre:series_index`), темы
   (`dc:subject`). Имя автора — через ту же нормализацию, что у FB2.
   Жанр — по памяти библиотеки (где уже лежит автор/серия) или по
   соседям; иначе «Входящие».
3. **PDF / DJVU — по имени файла и папки**: метаданные внутри обычно
   пустые или мусорные; разбор «Автор - Название» и подпапок — тем же
   способом, которым fb2parser разбирает пути.
4. **Мусор** — обложки (`.jpg`, `.png`), `.txt`, `.nfo`, `.url`,
   `.torrent`, `.sfv` и т. п. — удаляется при уборке, как сейчас.

Всё, что не удалось уверенно отнести к автору, — во «Входящие» (как
спорные FB2), а не молча удаляется и не копится. Чтобы «Входящие» не
копились тоже — еженедельное напоминание в Telegram, что там лежит.

## Предлагаемый порядок реализации

1. **Безопасная уборка.** Уборка удаляет папку только если в ней не
   осталось ничего, кроме мусора (п. 4). Папки с книгами других форматов
   остаются в папке наблюдения и попадают во «Входящие» с пометкой
   «не FB2». Касается и ручной синхронизации (код общий).
2. **Способ 1 — по соседям-FB2**: не-FB2 файлы обработанной порции
   раскладываются вслед за FB2 той же папки; не-FB2 порции без FB2 —
   во «Входящие».
3. **Способ 2 — EPUB/MOBI по метаданным** (через `book_tools`).
4. **Способ 3 — PDF/DJVU по имени файла**.
5. «Входящие»: решение по не-FB2 файлу (автор/жанр) так же, как по FB2;
   еженедельное напоминание.

Каждый шаг — отдельный коммит с тестами (фикстуры порций с EPUB/PDF/DJVU
рядом с FB2 и без них). Любая операция, кладущая файл в библиотеку, —
через `ownership_hooks` (как у FB2).

## Открытые вопросы (решает пользователь)

- **Дубли форматов.** Книга уже есть в библиотеке в FB2 — хранить рядом
  её EPUB/PDF (каталог покажет оба, читалка выберет) или удалять не-FB2
  копию как дубль?
- **Книги, которых нет в FB2** (например, DJVU Акунина) — класть в
  библиотеку к автору? Предложение: да, другого варианта книги нет.
- **Сжатие.** FB2 сжимается в `.fb2.zip`; EPUB/PDF/DJVU уже сжаты внутри —
  предложение: оставлять как есть.
- **Порядок.** Предложение: начать с шагов 1–2 (безопасная уборка + по
  соседям-FB2) — это закрывает большинство случаев без угадывания по
  метаданным; шаги 3–4 — вторым этапом.
