# Telegram-бот библиотеки для читателей — дизайн

Статус: в работе по этапам (см. конец). Дата: 2026-10-06.
Связан с `docs/watch-folder-autosync-design.md` (тот же бот и канал).

## Решения пользователя

| Вопрос | Решение |
|---|---|
| Где поиск и скачивание | В **боте** (личный диалог, кнопки, файлы); канал — только новинки |
| Кто пользуется | Только определённые люди: администратор заводит им аккаунты на сервере |
| Привязка Telegram | К аккаунту SOPDS — **только для бота и канала**, на вход на сайт не влияет |
| Форматы | Все четыре: FB2, EPUB, MOBI, AZW3 (как на странице книги) |

## Доступ

- **Привязка** (`sopds_web_backend/telegram_users.py`, модель `TelegramLink`):
  в профиле на сайте «Получить код» → одноразовый код на 24 часа и ссылка
  `t.me/<бот>?start=link_<код>`; открыл ссылку (или отправил код боту) —
  привязан. Один Telegram — один аккаунт. Отвязка — в профиле или
  администратором в списке пользователей.
- **Бот** обслуживает только привязанных к **активному** аккаунту; остальным
  объясняет, как привязаться.
- **Канал** — вход по ссылке «со вступлением по заявке»
  (`createChatInviteLink(creates_join_request=True)`, создаётся один раз):
  бот одобряет заявки привязанных, отклоняет чужих — утёкшая ссылка
  постороннему не поможет. Ссылку бот присылает сразу после привязки.
- **Удаление из канала** (ban + unban, без вечного бана): при отвязке, при
  удалении аккаунта и при его блокировке (`is_active=False`) — сигналы
  `sopds_web_backend/signals.py`.
- **Права бота в канале**: «Публикация сообщений», «Добавление подписчиков»
  (заявки), удаление подписчиков. Кнопка «Отправить тестовое сообщение» в
  настройках сообщает о недостающих.

## Поиск и скачивание (этапы B–C)

- Запрос — любой текст: совпадения по всем словам в любом порядке среди
  авторов, серий и названий; результаты — страницами по 10 с кнопками;
  автор → его серии и книги, серия → тома, книга → карточка (автор, серия,
  аннотация) с кнопками форматов.
- Файл — тем же кодом, что сайт (`opds_catalog/dl.py`: чтение книги и
  конвертация вынесены в общие функции); лимит Bot API на отправку — 50 МБ.
- Отправленный однажды файл Telegram запоминает (`file_id`): повторно та же
  книга в том же формате уходит мгновенно, без загрузки и конвертации.

## Связь с каналом (этап D)

В сводке новинок — ссылки-переходы в бота (`t.me/<бот>?start=s<id серии>` /
`b<id книги>`): открывают у читателя серию/книгу с кнопками скачивания.
Работают без публичного адреса сайта.

## Этапы

1. ✅ **A. Привязка и доступ к каналу**: модель и миграция, профиль, список
   пользователей, привязка в боте, заявки в канал, удаление из канала,
   проверка прав бота.
2. **B. Поиск и навигация** в боте.
3. **C. Скачивание** в четырёх форматах, кеш `file_id`.
4. **D. Переходы в бота** из сводки канала.
