## 2. Убрать недетерминизм многопроцессности — ✅ Готово

`Pass1ReadFiles.execute()` собирал `records` в порядке ЗАВЕРШЕНИЯ
воркеров (`concurrent.futures.as_completed`), а не в стабильном
порядке — из-за чего последующий консенсус (порядок слов в имени
автора, дробные номера подсерий типа "2.1"/"2.2", капитализация серий)
иногда давал разные результаты между прогонами без изменения кода.

Фикс: `records.sort(key=lambda r: str(r.file_path))` сразу после сбора
результатов в `pass1_read_files.py`. Проверено на полной библиотеке
Test1 (~12000 файлов): два подряд прогона одинакового кода дали
**0 расхождений** (было — десятки на каждую пару прогонов). Diff
против baseline (без фикса) — 172 записи, все относятся к уже
известным категориям недетерминизма (имя автора, капитализация серии,
перестановка дробных номеров), теперь зафиксированы в одно конкретное
значение; данных не потеряно.

## 3. Задокументировать приоритет источников — ✅ Готово

`docs/series-priority.md` — единый источник правды: иерархия
folder_dataset > folder_hierarchy > filename_prefix > filename_named_arc
> metadata, правило коллизий номеров, ссылки на код и тесты. Указатель
добавлен в docstring `regen_csv.py`.

## 4. Ревизия конфиг-патчей (`author_surname_conversions` и т.п.) — не начато

**Требует домашней библиотеки пользователя** (~80К файлов) — точечные
записи в `src/fb2_data/settings/app_settings.json` (например,
`author_surname_conversions`) накапливались как затычки под конкретные
книги. Нужно пройтись по списку и проверить, какие из них всё ещё
актуальны/нужны, а какие устарели (книга переименована, автора больше
нет в библиотеке и т.п.).

**Как выполнять:** запустить `python scripts/build_regen_fixtures.py
<путь_к_домашней_библиотеке>` НЕ для сборки fixture (это отдельная
задача — искать НОВЫЕ краевые случаи полным прогоном regen_csv/
find_groups по всей библиотеке, см. README.md в п.1), а затем отдельно
пройтись по `author_surname_conversions`/аналогичным спискам в
`app_settings.json` и для каждой записи проверить, есть ли в текущей
библиотеке файл, к которому она реально применяется.
