# Аудит regen + компиляции на «СЕРИЯ.LitRPG» (начат 2026-10-12)

Тестовый прогон на основном сервере, библиотека не изменялась: CSV и
группы — во временные файлы. Цель — тщательно проверить авторов, серии и
группы компиляции на большой коллекции (8 776 книг, 14 ГБ).

## Где лежат результаты

- **На сервере** (`ssh sopds-modern`), `/tmp/litrpg/` — `/tmp` переживёт
  только до перезагрузки:
  - `regen.csv`, `records.json` — результат regen (8 776 записей);
  - `groups.json` — группы компиляции с суффиксами (на момент записи ещё
    считался: 1 660 групп найдено, шёл расчёт названий);
  - `trace.txt` — трассировка подозрительных файлов (стоит в очереди после
    основного прогона: `/tmp/litrpg_trace.sh`, итог в `trace_timing.txt`);
  - `timing.txt` — время этапов.
- **Локально** `src/fb2_data/csv/litrpg-audit/` (не коммитится): копии
  `records.json`, `regen.csv`, `groups.json`, `trace.txt` (забраны
  2026-10-13 — прогон и трассировка завершились ночью) и скриптов:
  - `litrpg_run.py` — прогон regen + find_groups → JSON (запуск на сервере:
    `nice -n 15 ionice -c3 /opt/sopds-modern/.venv/bin/python /tmp/litrpg_run.py 'СЕРИЯ.LitRPG' /tmp/litrpg`);
  - `litrpg_analyze.py <каталог> [N]` — отчёт по 23 категориям (A — авторы,
    S — серии, G — группы);
  - `rts_full.py` — трассировка смен полей у файлов по подстрокам пути.
- Время: regen ~19,5 мин, find_groups ~10 мин, суффиксы групп — 15+ мин
  (2 ядра, сервер нагружен полностью).

## Общая картина

- Серия есть у 8 690 из 8 776 книг; источник серии почти везде
  `folder_dataset` (8 583). Источник автора — `folder_dataset` (8 446),
  `+metadata-coauthors` (291).
- Структура: `СЕРИЯ.LitRPG/Hеофициальная серия книг (разные издательства)/
  <Фамилия-Имя>/<Серия>/NN. Книга.fb2` (в «Hеофициальная» первая буква —
  латинская H) и `.../Книги, выпущенные издательством/...`.

## КРИТИЧНО — компиляция удаляет уникальные книги (2026-10-13)

`verify_dups.py` (в папке артефактов; запуск на сервере) проверяет каждый
«дубль на удаление» по содержимому: доля 6-словных фрагментов удаляемого
файла, найденная в остающихся файлах группы. Результат
(`verify_dups.txt`): из 47 «дублей» в 29 группах настоящих — 4 (Гаркушин
«Наследник Арисара» 100%, Горностаев «Ролевой синдром Ребилд» 83%,
Михайлов Дем «Великий Поход» 98%, Муравьев «Угроза клану» 100%).
**43 файла — уникальный текст (0–2% совпадения), применение компиляции их
удалило бы.** НЕ применять компиляцию на LitRPG до исправления.

Механизмы (по выводу групп, ещё не трассированы):
- «Том 1 и 2» в первом файле + следующий файл «Том 3» с префиксом «2.»:
  префикс-номер 2 попадает в диапазон 1-2 → «покрыт» → дубль (Вяч
  «Претендент», Губарев ×2, Манцуров, Розальев, Жанпейсов, Татуков,
  Amazerak, Коткин «Часть 1-2» + «Часть третья», Крынов «Том 1. Том 2»);
- номера глав приняты за тома: Сионг «Ark» — «The_Ark_-_Tom_X_-_Glavy_1-9»
  → диапазон 1-9 → удаляются тома 1–9; Rassvet Argos «Империум 1-168»;
- предкомпиляция по ошибке: Нукланд «3. Падение. Том II» → удаляет Лимрак,
  Роган, Лик Кальмуара и Том I; Раздоров «Том Четвёртый. Гримуар» → удаляет
  2–4; Власов «Книга Третья» → удаляет Первую и Вторую; AinDiGrimm
  «04. Том 4» (метка 1-4) → удаляет тома 1–3; Гарцевич, Голд Джон;
  Усачев «Книга 1 (Том 1-3)» → удаляет Книги 2 и 3; Тайниковский
  «Том VII - VIII» удалён рядом с «Алхимик IX-X» (метка 7);
- части одного тома под одним номером: Коршунов «Древние боги. Том 2»
  (Том 1 и 3 остаются), Ральт «Конвейер душ. Часть 1»;
- совпадение названия в разных подсериях: Шаман «4. Демон Разума/1. Часть
  первая» = «3. Универсал/1. Часть первая»;
- Емельянов: «Мир Царя зверей/1. На полную мощность» (другая книга);
- Калашников «Между сном и явью» — старая редакция (22% общего текста),
  удаление спорно.

Предложение: общая страховка в компиляторе — файл помечается дублем,
только если его текст действительно покрыт остающимися файлами группы
(≥ 0.7), иначе он остаётся в группе; плюс починка самих механизмов.

## Причины из трассировки (`trace.txt`)

- «Дикарь», «Сумрак», «Мир», «Ал» — `regen_csv._postcheck_clear_author_as_series`
  (≈ стр. 2599): серия, совпавшая с именем автора, известного в прогоне
  (в коллекции есть авторы-псевдонимы «Дикарь», «Сумрак», «Мир»; «Ал» —
  ещё и в male_names), стирается у ВСЕХ авторов.
- «S.T.A.L.K.E.R» — `pass2_series_filename._apply_folder_series` (стр. 1160),
  series_folder_blacklist.
- «S-T-I-K-S» — `regen_csv._postcheck_clear_universe_keyword_series`
  (стр. 1709): серия-вселенная сама по себе стирается вместе с номером.
- «Бета-версия» — `_apply_folder_series` (стр. 975) взял серией папку
  автора «Лысенко-Виталий (VampiRUS)» (folder_hierarchy), потом
  `pass4._cleanup_folder_hierarchy_series` её стёр — серия «Бета-версия»
  потеряна. Папка автора с псевдонимом в скобках не узнана.
- «Бакланов-Серегей» — папка автора с опечаткой («Серегей») ушла в корень
  серии, `_resolve_hierarchical_flat_mismatch` закрепил как named_arc
  (корень не совпадает со словами автора «Бакланов Сергей»).
- «В.-Виктор» — `pass2._prepass_folder_setup` (стр. 486) взял серией саму
  папку автора (файл лежит прямо в ней).
- «Сигел-Джейсон (соавт. Миллер-Кирстен)» — `_regen_series_from_folders`:
  имя папки режется по «(», «Миллер-Кирстен)» уходит в корень серии.
- «Сопряжение. Чернильный маг» → «Сопряжение» —
  `pass4._dotted_series_to_subseries` (стр. 723) свёл к корню, хотя рядом
  папка «Сопряжение» с другим подциклом (ЗИЛ).
- «Старатели. Новая история» → «Старатели» уже в
  `_regen_series_from_folders` (извлечение серии из имени папки режет
  «. Новая история»).
- Постернак «2. Кредо наемника» — номер 1 из метаданных, префикс имени
  файла «2.» его не перебил.
