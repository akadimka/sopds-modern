# Подключение Telegram

Пошаговая настройка Telegram для SOPDS-MODERN: уведомления о новых книгах
в канал, сообщения суперпользователю, коды входа, бот библиотеки для
читателей. Всё настраивается на странице **Настройки → Расписание**,
раздел **Telegram**.

Если сервер в России, сначала сделайте [ретранслятор](#1-если-сервер-в-россии-ретранслятор)
— `api.telegram.org` оттуда заблокирован.

---

## 1. Если сервер в России: ретранслятор

### Как понять, что он нужен

«Отправить тестовое сообщение» отвечает «Сервер не может достучаться до
Telegram» (`Network is unreachable` или таймаут). Проверка на сервере:

```bash
curl -4 -sS -o /dev/null -m 15 -w "%{http_code}\n" https://api.telegram.org/   # 000 — заблокирован
```

Обычный HTTP/SOCKS-прокси за границей не поможет: имя `api.telegram.org`
в нём видно, и фильтрация блокирует его так же. Нужен ретранслятор —
бесплатный Cloudflare Worker. Бот сам опрашивает Telegram (long polling),
входящие подключения к серверу не нужны.

### Создание Worker

1. Аккаунт на <https://dash.cloudflare.com> (бесплатный тариф: 100 000
   запросов в сутки — с большим запасом).
2. **Workers & Pages → Create → Create Worker** (шаблон «Hello World»),
   имя, например, `sopds-tg-relay` → **Deploy**.
3. **Edit code** → заменить код содержимым
   [`deploy/cloudflare-telegram-worker.js`](../deploy/cloudflare-telegram-worker.js)
   → **Deploy**.
4. **Settings → Variables and Secrets → Add**: имя `ALLOWED_BOT_ID`,
   значение — номер бота (цифры токена до двоеточия, например `7770001`)
   → **Deploy**. Без этого через ваш Worker смогут работать чужие боты.
5. Адрес Worker — вида `https://sopds-tg-relay.<аккаунт>.workers.dev`
   (виден на странице Worker).

Токен бота проходит через Worker, но не хранится в нём и не пишется в
журналы.

### Проверка доступа с сервера

```bash
H=sopds-tg-relay.<аккаунт>.workers.dev
curl -4 -sS -o /dev/null -m 15 -w "%{http_code}\n" https://$H/bot1:FAKE/getMe
```

- **404** — Worker доступен и отказывает чужому боту, всё в порядке.
- **000** и `Connection reset by peer` — из России заблокированы адреса
  Cloudflare, на которые указывает DNS (на 2026-10-22 —
  `188.114.96.x` / `188.114.97.x`). Cloudflare отвечает за любой свой сайт
  на любом своём адресе, поэтому имя Worker можно привязать к доступным
  адресам.

  Найти доступные (нужен ответ 404):
  ```bash
  for ip in 104.16.248.249 104.16.196.131 104.21.0.1 162.159.140.1 8.6.112.5; do
    curl -4 -sS -o /dev/null -m 10 --resolve $H:443:$ip -w "$ip -> %{http_code}\n" https://$H/bot1:FAKE/getMe
  done
  ```
  Два доступных адреса из разных диапазонов — в `/etc/hosts` (если один
  перестанет отвечать, будет использован второй):
  ```bash
  cp -p /etc/hosts /etc/hosts.bak-$(date +%Y%m%d)
  cat >> /etc/hosts <<EOF

  # Telegram-ретранслятор SOPDS: адреса Cloudflare 188.114.96.x/97.x из России сбрасываются
  104.16.248.249  $H
  162.159.140.1   $H
  EOF
  ```
  Перезапускать ничего не нужно.

## 2. Поля раздела Telegram

Заполняйте по порядку: без сохранённого токена кнопки не работают.

### Сначала — и «Сохранить»

1. **Токен бота.** Создайте бота у [@BotFather](https://t.me/BotFather)
   командой `/newbot` и вставьте токен вида `123456789:AAH…`. Можно вставить
   сообщение BotFather целиком — токен вытащится сам. После сохранения
   токен на странице не показывается (только последние 4 символа); пустое
   поле при следующих сохранениях оставляет прежний.
2. **Адрес Bot API** — адрес Worker из раздела 1, если сервер в России;
   иначе пусто (используется `api.telegram.org`).
3. **Прокси** — оставьте пустым. Нужен, только если сервер вообще не
   выходит в интернет напрямую (`http://user:password@host:3128`).
4. **Адрес сайта для ссылок** — адрес сайта, например
   `https://books.example.org`. Из него строятся ссылки в сообщениях (на
   новые книги и на «Входящие»); без него сообщения придут без ссылок.

Нажмите **«Сохранить»**.

### Затем — канал и ваш чат

5. **Канал для новых книг.**
   1. Создайте в Telegram канал (можно закрытый).
   2. Добавьте бота в канал **администратором** с правами: публикация
      сообщений, добавление подписчиков, удаление подписчиков (последние
      два нужны боту библиотеки — заявки на вступление и удаление
      отвязавшихся).
   3. Опубликуйте в канале любое сообщение.
   4. Нажмите **«Найти chat id»** — в таблице появится канал с id вида
      `-100…`. Впишите его (у публичного канала можно и `@имя_канала`).
6. **Chat id суперпользователя** — ваш личный чат с ботом, туда приходят
   отчёты и вопросы автосинхронизации.
   1. Откройте своего бота в Telegram и нажмите **Start**.
   2. Нажмите **«Найти chat id»** — строка с типом `private` и вашим
      именем. Впишите её id (только цифры).

Снова **«Сохранить»**, затем **«Отправить тестовое сообщение»**: должны
прийти два сообщения — в канал и вам лично, на странице — две ✅.

«Найти chat id» видит сообщения только за последние ~24 часа: если таблица
пустая — снова Start в боте или сообщение в канал, и повторите.

## 3. Бот библиотеки для читателей (необязательно)

Поиск и скачивание книг в боте, привязка аккаунтов, вход в закрытый канал
— `docs/telegram-library-bot.md`. Работает в службе `sopds-telegram`
(DEPLOY.md, раздел 19a, шаг 6):

```bash
systemctl enable --now sopds-telegram
```

Пока служба работает, «Найти chat id» показывает чаты, которые видел бот;
свой chat id можно узнать, отправив боту `/id`. После смены токена или
адреса Bot API служба подхватывает их сама; после обновления кода —
`systemctl restart sopds-telegram`.

Читатели привязывают Telegram сами: **профиль → Telegram → «Получить код
привязки»** (с паролем) и отправляют код боту.

## 4. Если не работает

Текст после ❌ в ответе кнопок подсказывает, что не так.

| Сообщение | Что сделать |
|---|---|
| «Сервер не может достучаться до Telegram» | Сервер в России — раздел 1; проверить адрес Bot API и `/etc/hosts` |
| HTTP 403, `error code: 1010` | Cloudflare отклоняет клиента — обновить SOPDS-MODERN до v2.28.001 или новее |
| HTTP 404 через Worker | Неверный `ALLOWED_BOT_ID` (не номер этого бота) или код Worker не тот |
| «Неверный токен бота…» | Скопировать токен заново из сообщения @BotFather |
| «Бот не может написать первым…» | Открыть бота в Telegram и нажать «Старт» (Start) |
| «Чат не найден…» | Проверить id; для личного чата — сначала «Старт» в боте |
| «Бот не может публиковать в канале…» | Сделать бота администратором канала с правом публикации |

Связь пропала, хотя раньше работала, — вероятно, под блокировку попали
адреса из `/etc/hosts`: проверить их командой из раздела 1 и заменить.
